## ♿ Accessibility Features

Accessibility is a core part of Winget-Dashboard. The application is built for users who depend on screen readers and keyboard navigation, and it aims to remove barriers that often appear in software management tools.

Key accessibility points include:

- Screen reader support, including NVDA.
- Keyboard-friendly navigation so you can move through the dashboard without a mouse.
- Clear labels and controls that describe what each action does.
- A layout designed to reduce clutter and make important information easy to find.
- Feedback for actions such as searching, installing, and updating software.

If you use NVDA, launch it before opening Winget-Dashboard. You can then use your usual screen reader commands to explore the window, read results, and activate buttons. The goal is to make software management usable for everyone, including people who cannot rely on visual cues alone.
